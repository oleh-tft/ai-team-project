Студентський проєкт з штучного інтелекту



Цей проєкт присвячений вивченню та практичному застосуванню технологій штучного інтелекту і складається з трьох основних завдань.



Завдання 1



Аналіз генерації зображень за допомогою моделей ChatGPT Image та Gemini Nano Banana. У межах завдання проводиться порівняння якості генерації, особливостей роботи моделей та отриманих результатів.



Завдання 2



Асистент для ноутбука — LLM-помічник викладача, реалізований на Python. Асистент працює з документацією, книгами, збірниками задач та іншими навчальними матеріалами, а також надає посилання на використані джерела.



Завдання 3



Інтелектуальний агент на платформі n8n зі спеціально розробленим API для розрахунку найбільш вигідних кошиків товарів у магазині.
